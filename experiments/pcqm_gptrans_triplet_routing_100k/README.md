# Triplet routing100K

[Protocol](protocol.md) freezes the recovery/new-routing questions. Thin
`freeze.py` and `accept.py` reuse native GPTrans release, saved-output acceptance
and per-arm RML closure. No new training or acceptance framework is introduced.
Live state belongs in root `CURRENT_STATE.md`. The deferred full50K portability
action is packaged before submission, but is not an executable audit release.

The [terminal interpretation](gpu/results/interpretation.md) owns the accepted
endpoints, matched-curve attribution and closure. The
[audit disposition](gpu/results/post100k_audit_disposition.json) keeps the
unexecuted full-role qualification gap separate from training acceptance.
