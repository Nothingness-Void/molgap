# K1 Muon100K

One same-job Kaggle2 pair: original K1 with AdamW versus the identical original
K1 with hidden-matrix FP32 Muon and remaining-parameter AdamW. Both arms are
newly trained from the same original random initialization.

[Protocol](protocol.md) owns the scientific question, A/B/C review, conditions
and gate. [Status](STATUS.md) owns execution progress. [Decision](decision.md)
is pending until retained real evidence is accepted. No500K/full release.
