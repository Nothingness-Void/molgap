# GPTrans persistent-pair readback, matched 100K screen

This desktop-owned question tests whether node readback should use the accumulated
pair state instead of only the current layer's relation update. The protocol
owns the frozen comparison and resource gate; `launch_decision.md` authorizes
one matched Kaggle1 T4x2 attempt. `STATUS.md` records the remote run separately
from scientific acceptance. Per-arm prospective RML records live under
`prospective/` and are created by the shared experiment CLI.

No official validation, test-dev, or challenge role is released.
