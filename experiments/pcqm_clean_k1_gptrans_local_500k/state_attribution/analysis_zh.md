# K1 500K 退化的本地状态归因

日期：2026-10-15 JST。这是原实验的授权后续诊断，不是新训练或模型晋升。
使用同一批已消费的 50K 内部开发成员，另取 4,096 个训练成员做固定口径描述。
训练描述样本与两套 BN 校准成员均不重叠。官方验证、测试及 Track A 角色未访问。
完整数字、逐行区间和运行身份见 [result.json](results/result.json)；
[协议](protocol.md) 在执行前冻结，原训练结果和 RML 排除项不改写。

## 1. 已确定：本次固定前缀 Clean-BN 输出状态损失明显

最佳 checkpoint 为 pass32 / step124992。下表前三行使用同一份 EMA 学习权重：

| 输出状态 | 内部开发 MAE/eV | 相对 Raw EMA |
|---|---:|---:|
| Raw EMA，保留原缓冲 |0.105396973|参照|
| 原正式输出：前 16,384 训练成员 Clean BN |0.109049479|差 3.653 meV|
| 固定均匀 16,384 训练成员 Clean BN |0.105419359|差 0.022 meV|
| Live 权重，经相同均匀成员 Clean BN |0.110536673|不同权重的控制，不作同权重差分|

Raw→原 Clean 只换 BN 缓冲，误差增加 3.653 meV，配对行 95% 区间
[3.412,3.902] meV。原 Clean→均匀校准恢复 3.630 meV，区间
[3.402,3.868] meV。保持校准数量、批大小、累计估计、关闭 dropout 和学习权重不变。

另外，同一 Live 权重在本地用同一个校准函数：前缀校准为 0.113723408，
均匀校准为 0.110536673，恢复 3.187 meV，区间 [2.950,3.437] meV。
这组控制独立支持校准成员选择的影响；没有证明具体是哪种分子化学分布造成。
EMA 原前缀缓冲来自原生 T4，均匀缓冲在本地 CPU 重估，不宣称已隔离全部
跨后端校准数值效应。原 Clean 推理在 CPU 复现的最大逐行差仅 2.861e-6 eV。

因此，这是“产物合法，但当前前缀校准策略不适合这份权重”的证据。
不是发现陈旧 checkpoint、权重错装或一次软件崩溃，也不是所有 Clean BN 都有害。

## 2. EMA 不是本次应直接删除的模块

相同均匀成员、相同校准程序下，Live 为 0.110536673，EMA 为 0.105419359；
EMA 少 5.117 meV，行区间 [4.767,5.451] meV。这是固定 checkpoint 的权重状态比较，
不是重新训练 EMA/非 EMA 的因果试验，也不能外推为所有规模的 EMA 收益。

## 3. 后期变化依赖输出状态，不能笼统归因为过拟合

| 状态 | pass32 开发 MAE | pass60 开发 MAE | 变化/meV |
|---|---:|---:|---:|
| Live |0.109987658|0.105920457|改善 4.067|
| Raw EMA |0.105396973|0.106017171|变差 0.620|
| 原前缀 Clean EMA |0.109049479|0.110085445|变差 1.036|

三种状态对应的固定训练样本误差均下降；Raw EMA 的训练误差下降 12.666 meV，
开发误差却增加 0.620 meV。这与该状态的末期泛化差距扩大相容，但 Live 开发
同时明显改善，不能据此判定整个 K1 后期必然过拟合。只保留两个时间点也无法
重建完整 Raw/Live 最优轮次，不能据此安装提前停止或重选原正式 checkpoint。

## 4. 历史差距还剩什么

原正式 Clean 0.109049475 与历史干净 K1 0.103658948 的差是 5.391 meV，
不是本次 pass32→60 的差。当前同一步 Raw EMA 与历史点的背景差约 1.738 meV。
这是算术背景，不是对历史差距的严格可加因果分解，更不是通过晋升门槛。

历史模型复用 100K/10-pass 预训练骨干，使用双前向一致性并按 Live 选模；
本次从随机权重开始、单前向、按 Clean EMA 选模，余弦计划及执行源码也不同。
详见 [配方审计](recipe_comparison.md)。剩余差距不能唯一归因于某一训练因素。
没有证据把它归因于单 Slot、低有效秩或加速代码。

## 5. 处置

优先修正下一份合同的输出选择/校准设计，而不是立即扩 Slot、换 Mamba 或删除 BN。
Raw EMA 和固定均匀校准值得作为后续预注册候选；本次后验诊断不自动替换原正式结果。
不补跑基线，不重训 60 passes，不修改生产默认，不启动远端作业。
诊断以 NO_TRAIN 闭环；保留原两条训练轨迹的 INCONCLUSIVE 和 replay exclusions。
CPU 数值工作约 467.420 秒、1,798.234 CPU-process 秒；GPU 未使用。
准备、测试、源码审查与独立验收不混入这一个 worker 的成本。
