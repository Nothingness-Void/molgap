# Clean K1 and local-bond GPTrans at500K

Desktop-owned, user-authorized two-candidate training question. No reference is
retrained. [Protocol](protocol.md), [evidence review](evidence_review.md),
[status](STATUS.md) and [decision](decision.md) own this question.

The shared family session trains both arms. K1 changes the declared EMA
selection state to freshly calibrated training-prefix BN. GPTrans transfers
the already registered degree/bond-local100K recipe to the fixed500K selection.
This is not a causal K1-versus-GPTrans architecture comparison or full release.

Each arm retains its own prospective RML, source/config/input identities,
native qualification, selected state/predictions, trace, resume, roles and costs.
Use `molgap-experiment-reuse` and `kaggle-molgap-workloads` for preparation and
the existing family output/RML terminal routes for acceptance.
