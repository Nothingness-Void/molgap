# GPS7 Distillation

**Question:** Can a smaller GPS7 student retain the exact-2M teacher's external
accuracy?

**Verdict:** No. Internal validation passed, but fixed external retention
failed; the student is not a production replacement.

Read `distilled_2m_scnet/decision.md` for training evidence and
`distilled_2m_external_eval/decision.md` for the rejection gate.
