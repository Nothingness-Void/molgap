# EdgeState 304 at 500K

This experiment asks whether the user's persistent-edge GPS remains useful at
the 304-channel width used by GraphGPS-small, and whether local relation
pretraining improves that fixed encoder under equal sample exposure.

The immutable protocol is [protocol.md](protocol.md). Remote artifacts are
written under a dedicated SCNet root and are not part of Git. No official
validation or test role is opened by this experiment.
