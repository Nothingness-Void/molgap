# Geometry V4 500K launch decision, 2026-09-28

The user authorized one Kaggle1 500K submission and asked for a second
evidence-backed route in the same two-arm allocation. The existing accepted
pure-2D GPTrans-T and K1 V4 references are reused rather than retrained.

The GPTrans distance-only arm addresses the unresolved 100K contextual gain
against pure 2D. The K1 distance-angle arm tests whether the historical
geometry K1 prediction can contribute under the same matched 60-epoch V4
recipe; the earlier geometry GPTrans/K1 fixed 50:50 and OOF blends were more
accurate than either component on a consumed internal-development role. The
old geometry runs lack a matching V4 reference and certificate. Thus their
scores motivate a bounded confirmation, not a promotion claim.
The exact executable and budget declaration is `training_contract.json`.

The 100K GPTrans angle increment, centered logits, pair-memory, and existing
500K PairNorm/Noisy Nodes directions did not pass their gates. They are not
repeated. Both new arms must independently satisfy their strict reference,
cost, artifact and trace checks. If either route fails remote preflight, the
kernel does not release training. A partial stage is not a terminal scientific
decision and requires accepted resume identity before continuation.
