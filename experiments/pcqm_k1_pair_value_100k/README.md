# K1 PairToken key/value decoupling

This desktop-owned prospective V5 experiment asks one new information-flow
question: can the accepted PairToken selector keep its normalized relation keys
while learning an independent relation-value encoding?

The candidate preserves K1, the layer-6 ordered-pair set, per-pair LayerNorm,
the learned selector, one relation token, token processor, and broadcast return.
It adds one bias-free `32 x 32` identity-initialized value projection. The
zero-initialized return keeps the initial graph function exactly equal to K1.

Only the fixed 100K train and 50K internal development roles are allowed.
Official validation, test-dev, and test-challenge are forbidden. A terminal
result does not authorize a 500K or full-scale successor.
