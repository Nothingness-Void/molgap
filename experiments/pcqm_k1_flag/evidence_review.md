## Selected new question

Supervised gradient-directed atom-embedding perturbation was literature-only,
with no executed FLAG question found by the indexed local canonical/Git census.
It tests a learning constraint rather than introducing new molecule observations.
The observed deficiency is failure of simple capacity expansion to deliver a
material development gain, with useful local/slot paths preserved. Sensitivity
to latent perturbations is unmeasured, not a diagnosed reason for those failures.

FLAG averages model gradients over three increasing perturbation scales and
updates weights once. Reference: [CVPR2022 paper, methods/Algorithm1](https://arxiv.org/html/2010.09891).
It differs from categorical masking, Gaussian Noisy Nodes with reconstruction,
training-only fingerprints and sequential pretraining. Its molecular
classification results include both improvements and regressions; no PCQM Gap
gain establishes transfer. The official classification runner hardcodes300
channels and BCE, so reuse the algorithm with192-channel embeddings and the
existing normalized Gap L1, not that task runner.

## Alternatives and falsifiers

The perturbation may be irrelevant or harm clean regression. Extra repeated loss
evaluations, changed dropout samples and optimizer behavior can explain effects;
there is no equal-compute adversarial-direction control. A successful endpoint
would nominate only the complete recipe, not prove direction-specific causality.
The bounded train-only CPU probe checks clean-forward identity, finite nonzero
perturbation gradients, sensitivity and exact accumulated-gradient semantics.
It does not predict generalization or prove smoothness is desirable. Remote
real-batch T4 qualification then checks replay, resume, clean selected-state
inference and native cost before any formal updates. The only scientific
falsifier is one complete predeclared100K/40epoch candidate versus the retained
original reference; no parameter sweep, seed search, early-curve screening or
automatic successor.
