# Baseline presets

Versioned, hash-pinned baselines for the scientific input compiler. A preset pins
the recipe, data declaration, target manifest, initialization digest and model
family; it carries no question, authority or evidence. Never edit a released
version: add `vN+1`. See the [quickstart](../../docs/operations/EXPERIMENT_QUICKSTART.md#supply-one-human-input).

- `k1-post-bn-100k-v1.json`: K1/3 post-BN 100K recipe; data declaration `k1-post-bn-100k-data.json`.
