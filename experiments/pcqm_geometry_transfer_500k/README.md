# Geometry transfer at fixed PCQM 500K

This experiment asks whether the already accepted ETKDGv3+MMFF bond-distance
and bond-angle channels improve the GPTrans-T and one-slot Neural-Atom K1
information-flow cores. The frozen protocol is in [`protocol.md`](protocol.md)
and the authorization decision is in
[`launch_decision.md`](launch_decision.md). Live remote state is in
[`STATUS.md`](STATUS.md). The post-launch audit against the newer reference
screen contract is in [`v4_comparability_audit.md`](v4_comparability_audit.md).

No official validation, test-dev, or test-challenge role is available to this
experiment.
