# GPTrans full-step profile

This profiling-only experiment decomposes the frozen V5 GPTrans-T training
step on the accepted fixed 500K train cache. It produces runtime evidence only;
it does not evaluate a model or change a scientific contract.

See `protocol.md` for the frozen question, `profiling_contract.json` for the
machine-readable limits, and `STATUS.md` for the remote attempt identity.
