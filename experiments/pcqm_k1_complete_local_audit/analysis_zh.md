# K1 完整解析、可达范围与下一步路线

日期：2026-10-08。结论依据保留的规范证据、本地冻结模型诊断及原始训练记录。
此报告统一覆盖编码、结构信息、边记忆、局部消息、FFN、BN、slot、readout/head、
Dropout/一致性、预训练、教师、权重状态、曝光、速度及融合。
本次没有训练，没有远端执行，没有消耗 A100/T4，没有使用官方验证或测试角色。

## 1. 结论先行

**K1 目前没有证据支持“已经碰到不可突破的精度上限”。也没有证据支持下一步盲目加宽、
增加 slot、补更多 epoch 或再叠一个关系模块。** 当前能明确归因的是输出状态和执行工作量；
完整训练配方中各项对 500K 泛化的因果贡献仍需既有消融回答。

1. **慢有直接工作量原因：两次随机前向。** A100 冻结执行剖析中，双前向训练步比单前向多耗
   70.82%；原 T4 任务 K1 epoch 比 GPTrans 慢 43.84%。两者不是同一测量范围，不能把它们相减
   当成剩余开销，也不能直接保证 T4 提速比例。
2. **已有部分精度损失来自 BN 状态。** 对相同 K1 权重，只重估训练成员的 BN，完整 50K
   开发集 MAE 从 0.104904 降到 0.103659 eV，恢复 1.245 meV，约为原始 K1–GPTrans EMA
   差距的 41.28%。但还差 1.771 meV，BN 不是全部解释。
3. **更多末期曝光没有救回来。** 完整 50K 对照中，同样干净 BN 后 epoch 60 比 epoch 49
   差 0.787 meV。49/60 等权参数平均仍比选中模型差 0.191 meV，等权预测平均也差 0.155 meV。
   这一种末期平均已经可以关闭；真正逐步 EMA 尚未得到有效 K1 结果。
4. **基础计算路径均有作用。** 干净 BN 的冻结模型中，14 个固定扰动全部变差；没有发现
   直接削弱某条路径即可改善预测的模块。这证明依赖，不证明结构最优或训练容量已满。
5. **100K 的“最好模型组”没有原样搬到 500K。** 最好的 100K 预训练组合含教师项，500K
   组合不含教师；此外 GPTrans 使用 EMA，K1 使用 live。不能把最终排序归因成“所有 K1
   提升包到了 500K 都失效”。
6. **K1 的确定价值仍然包括互补性。** 现有干净 K1 与 GPTrans EMA 固定各占一半，在同一
   已消费的 50K 开发集上达到 **0.098477 eV**，比 GPTrans 单模型好 **3.410 meV**。
   这是本地保留预测的描述结果，不是独立验收、全量准入或模型采用。

**下一步主线：先完成已提交的 500K 一致性消融，再围绕训练状态与每步工作量简化配方；
结构扩容降低优先级。** 没有新增远端任务，也没有重训基线。

## 3. K1 的真实结构：哪里有容量，哪里有约束

冻结模型共 **3,658,817 参数**，不是纯 slot 小网络。

| 部分 | 参数 | 结构与用途 |
|---|---:|---|
| 原子类别编码 |33,408|OGB 原子特征，192 维 |
| 键类别编码 |832|64 维初始边状态 |
| RWSE 编码 |40,320|16→192→192，SiLU；此处没有 BN |
| 持续边状态更新 |298,368|9 次，根据当前端点节点及上一次边状态更新 |
| 局部块 |3,004,992|9 个 ResGatedGraphConv + FFN；约 82.13% 参数 |
| 三处 Neural-Atom mixer |225,216|层 3/6/9；latent64，每处只有 1 个 active slot |
| 预测 head |55,681|mean readout 后 192→192→96→1，SiLU/Dropout |

局部块有 18 个 BN。不能把所有 BN、所有非线性或所有参数都归因于 slot。

**单 slot 的限制是真实的：** 每个 mixer 只有一套节点选择分布，单分子返回矩阵至多 rank1。
但返回叠加到 192 维残差，前两处返回还经过后续局部/边状态非线性，因此完整模型不等于
rank1。四个 attention head 也不是四条独立关系通道：slot self-attention 序列长为 1 时，
softmax 权重恒为 1，Q/K 不影响干净前向。三处合计约 25,536 个计数参数来自干净前向中
不起作用的 slot Q/K 和未激活 seed；这不意味着可直接删掉整个 mixer。

最后一次 slot 的 assignment 在节点上归一化，mean readout 中返回是 projected_slot/N。
存在随原子数缩放的结构关系，但本次测得层9返回/已有 pooled hidden 范数中位数约 **49.73%**，
层3约64.12%、层6约106.51%；返回并非数值上消失。历史最终 slot 归零使冻结误差大幅变差，
也反对“slot 无效”的说法。

后层主方差集中，确实存在压缩。但全部观察位置均无恒零/近恒定通道，最终 pooled 的平均
两两 cosine约0.0497，方差总量37.01；不同分子的表示没有全部变成相同向量。单标量 Gap
目标本来可能使用少数主方向，低有效秩不能直接当作信息丢失或可学容量上限。
历史跨尺度表示记录也显示误差改善可与某些秩下降同时出现。

slot选择的第一8个baseline batch，归一化熵均值：层3 **0.956**、层6 **0.994**、层9
**0.594**；有效关注原子数均值12.30、13.53、5.46。前两处接近广泛汇总，末层更有选择性，
不能说所有 slot 学成完全相同的均匀选择。此统计只含1,024个开发成员，不是全量证明。

**容量结论：** 需要新控制才能证明某种特定瓶颈；当前证据不足以支持 atom256、slot96、
K4、多 head、多层 readout 或 head扩宽作为优先路线。历史 atom256退化、K4退化以及
readout replacement退化，比“低秩所以扩维”更接近直接训练证据。

## 6. BN、Dropout、一致性和末期权重：分开解释

| 500K 冻结输出 | 完整50K MAE eV | 结论 |
|---|---:|---|
| epoch49 原BN |0.104904075|原选中 live |
| epoch49 干净BN |0.103658948|恢复1.245meV |
| epoch60 原BN |0.105724607|末期原始输出更差 |
| epoch60 干净BN |0.104446280|仍比49差0.787meV |
| 49/60权重各半＋49的BN |0.106325806|平均权重与旧BN不匹配 |
| 49/60权重各半＋干净BN |0.103849668|仍比49干净态差0.191meV |
| 49/60干净预测各半 |0.103813937|仍差0.155meV |
| GPTrans EMA |0.101887690|不同模型/配方的上下文对照 |

末期差距有完整50K的不确定性：final-clean变差CI[0.630,0.950]meV；average-clean变差
CI[0.111,0.274]meV。不能再用“只是末期BN漂移”解释所有差距，也没有理由机械补epoch。
这不是 true EMA 测试；逐步EMA利用的历史权重无法从两个checkpoint重建。

先前A100 BN机制测试：Dropout开启时估计BN，比关闭时差0.848/0.909meV；关闭Dropout重复
干净累计一遍几乎不变。这验证冻结BN估计条件的效果，**不验证训练Dropout有害、双前向必然
伤精度或一致性损失一定有害**。线上训练状态含随机Dropout和更新前/后差异，不能直接拿
训练MAE减干净开发MAE来断言欠拟合。

同BN口径的训练前缀/扩展描述误差本次为0.059902/0.057015eV，20/80加权约0.057592；
开发子集0.102406。存在已见成员与开发成员的拟合差距，但不诊断其来自特定模块，不声称
全部未预训练的扩展成员更难。此前末期前缀变差、扩展小幅改善且区间跨零，也反对简单的
“给所有数据更多曝光就一定提高”。

## 7. 100K提升为什么没表现为500K单模型优势

### 7.1 配方并不相同

100K pretrained+consistency A为0.138265848；加入教师的B为0.136781212，同任务增益
1.485meV，CI[0.759,2.197]。500K只用了A式teacher-free配方。
教师压缩仍落后教师约2.115meV，不能推断补上教师就一定超过GPTrans。

10pass预训练覆盖前100K，只有下游500K成员的20%；999,680次呈现约为下游29,998,080
呈现的3.33%。这是覆盖事实，不是曝光不足的因果证明。单独顺序预训练历史点增益约0.197meV，
严格结论INCONCLUSIVE，不能把“所有预训练均正向”作为前提。

### 7.2 对手也变强，且输出状态不同

旧desktop matched60：K1 0.104859870、GPTrans 0.106867528，K1领先2.008meV。
新组合：K1 0.104904077、GPTrans EMA 0.101887690。K1 contextual变化约+0.044meV，
GPTrans变化约−4.980meV。排序反转包含GPTrans增强和状态区别，不只是K1模块失效。
GPTrans同一EMA选择checkpoint中的live输出为0.103826756；live→EMA算术差1.939meV。
干净K1甚至比这个live输出好0.168meV，但它不是独立选择的live reference，因此不能
宣称“K1已经击败严格GPTrans基线”或保证K1 EMA也能得到1.939meV。

### 7.3 有些100K关系增益确实没有转移

PairToken、receiver/RRWP/triplet、degree balance、RWSE refresh的冻结100K权重，换到
固定500K开发成员后，许多优势已经下降或反转。由于权重未训练变化，不能全部归因于500K
训练步不足。数据成员/选择分布及小数据配方适配都可能参与。

PairToken早期500K比较使用0.104859870 scalar reference，报告+0.556meV；之后server
精确matched60 reference是0.103605195，对PairToken0.104303729为**退化0.699meV**。
要保留两条记录而不能混用。它的冻结关系路径被关掉会严重退化，说明模型使用了该路径；
同时不证明它胜过重新训练的K1。已有同epoch记录支持其规模相关泛化缺口，仍未唯一识别
容量、化学分布或正则原因。

## 9. K1 还能达到哪一步

### 单模型：当前可验证范围

本组合500K保留权重中，最好的已验证干净状态是0.103658948。它距GPTrans EMA0.101887690
还有1.771258meV。末期平均没有弥补这部分。没有证据能承诺加一个模块就到0.100或更低，
也不能根据有限干预断言K1永远不能达到该目标。

原full K1 checkpoint0.106672235，额外patience continuation未改善。full与500K角色、
曝光及schedule不同；它不构成单模型理论极限。当前任务不释放full。

### 融合：已有可用互补，仍需独立资格

保留完整50K预测，干净K1与GPTrans EMA固定50:50得到 **0.098477246 eV**；相对GPTrans
增益 **3.410444meV**，CI[3.079919,3.741040]。旧raw融合0.098859154，干净融合数值再低
约0.382meV。没有拟合融合权重，没有router，也没有执行新模型。

残差相关系数0.8601，K1在48.94%行上误差更小，19.91%行的残差符号相反。融合P99绝对误差
约0.59385eV，低于K1的0.60856和GPTrans的0.60610；中位、P90/P95也改善。
这解释“平均成绩较差的K1为什么仍有价值”，但不能从相关系数推导最优MoA架构。

4K探索切片中低Gap四分位K1比GPTrans好约3.015meV，其余较弱；16–25原子组点优势约
0.177meV，没有独立资格或训练方差。**真实Gap不能作为部署router输入**，该切片只用于
描述互补，不是已验证专家路由。26+原子组本样本为空，对大分子不下结论。

固定融合也不是full准入。之前full融合仍比accepted EdgeState差约2.588meV；既有官方
角色已消费，不允许把本次开发集结果外推为提交成绩。

## 10. 下一步：一条主线，两个问题分开验收

### 首先完成已经授权的500K一致性判别

替它查询或推进。weight0和0.1均为双前向，同曝光/预训练，必须分别验收raw与固定clean BN：

| endpoint不完整/参考不合格 |未知|补证据或如实关闭，不以新的任务代替验收 |

不能用这一pair测单前向提速，因为两arm都执行两次forward。

### 如需下一轮训练：K1训练状态与每步成本简化

这是**拟议路线**，不是已经授权启动的新训练合同。保留K1-v4编码器、边记忆、RWSE、宽度、
slot和现有预训练身份；不叠未知结构。依据上面pair的结论再冻结两条相近候选：

- **A：单前向、无一致性项，真逐步EMA。** 用于验证是否能以更少工作量保住干净精度。
- **B：保留经既有pair支持的双前向一致性，真逐步EMA。** 用于检验额外成本是否换来
  材料收益；若既有pair否定一致性，不启动重复的B，重新设计唯一尚未回答的状态控制。

每个arm同时保留live/EMA、完整step/exposure/resume、原BN与训练成员干净BN输出，且各自
独立选中模型/预测/成本/角色/RML。这使EMA状态比较在arm内完成，避免额外重训基线。
A/B比较的是“单前向配方”与“有证据支持的双前向配方”，不是将两个变化伪装成单变量
一致性因果试验。严格参考不足则pending，不为账本训练新基线。

问题预先拆开：

1. **精度**：真EMA是否改善同配方live且clean后仍保留收益；对已有严格参考的差距是否
   实际缩小。EMA效应没有可承诺数字；49/60平均失败不回答它。
2. **成本**：原生T4按loader、forward/backward、optimizer、dev、checkpoint/publication记录，
   按实际设备小时与达到目标误差的成本比较；不能把A100微剖析视作整个T4 epoch。

原3meV晋级合同不修改。若目标是提速而保持精度，应在运行前独立预注册非劣界、成本目标
及准确参考；不能事后因没过精度门槛改叫成功。

### 暂缓的路线和重开条件

扩维、多slot、新pair/triplet、更多epoch、重做蒸馏不进入当前优先队列。
只有状态/配方控制完成，且仍留下**特定可测容量或泛化缺口**时，才选择一种与已关闭机制
不同的结构干预。需要写清主问题、现有失败的区别、最便宜否证器、数据/成本合同，不能把
“现在还不能完全解释”当成提交任意模块的依据。
