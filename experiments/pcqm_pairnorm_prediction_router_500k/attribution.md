# Attribution

Exact prediction file digests, 50K ordered row IDs, targets and finiteness
passed. A prospective five-fold gate diagnostic consumed the previously
selected development role; no backbone training/inference or protected role.
The routing features are only existing prediction values and disagreement.

The pair's hard winner AUC is 0.5203 and hard routing worsens global weighting
by 2.636 meV. The soft gate gains only 0.254 meV (paired row-bootstrap gain
95% CI 0.154 to 0.350 meV). For the three-pass group it gains 0.160 meV
(0.086 to 0.239 meV). All five folds improve, but neither reaches 1 meV.
This reproduces the prior prediction-only gate's small gain on a new expert
pair, not a proof that molecular representations cannot improve routing.

The Oracle depends on unavailable labels and is not an achievable estimate.
Cross-fitting isolates gate-label fitting only; the experts were already
selected on these rows and row-bootstrap excludes retraining uncertainty.
Both predictions must be computed, so there is no conditional-compute saving.
Structure-aware OOF/embedding evidence and independent test remain absent.
