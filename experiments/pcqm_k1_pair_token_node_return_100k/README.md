# K1 PairToken node-return screen

This experiment asks whether PairToken's useful selected cross-node relation
token should return differently to each atom instead of broadcasting one
identical graph residual. It owns one seed-42 PCQM-100K architecture screen.

The immutable K1-v4 reference is reused from the recovered V5 bundle. Training
is blocked until `freeze_release.py` writes a release-qualified prospective RML
trajectory and `comparison_readiness_prelaunch.json` passes the server gate.
Terminal collection must add observed role events, trace, runtime, cost,
aligned predictions, paired analysis, acceptance, decision and RML rebuild.
