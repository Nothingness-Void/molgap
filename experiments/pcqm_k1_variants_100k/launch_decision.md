# K1 selective-global screen launch decision — 2026-09-12

The all-history attribution supported one bounded comparison between frozen K1
and two independent changes to its low-rank global allocation. The experiment
was admitted because K1-G conditions only exchange strength and K1-R adds only
an EdgeState-derived relation channel; neither repeats the rejected multi-slot,
path, geometry, attention, or pretraining mechanisms.

The user authorized a Kaggle2 split execution: one P100 arm for the reusable
K1-v4 reference and one T4x2 task with separately isolated K1-G and K1-R arms.
The immutable machine contract is `training_contract.json`; implementation and
scientific gates are in `protocol.md`. No result, promotion, additional seed,
scale-up, sealed-role access, or full training was established by this launch
decision.
