# K1 selective-global variants on fixed PCQM-100K

This experiment asks whether the frozen one-slot K1 global exchange should be
conditioned by molecule complexity (`K1-G`) or augmented by a distinct compact
relation slot (`K1-R`). Read `launch_decision.md` for the authorized question,
`protocol.md` for the frozen method, and `STATUS.md` for remote state. A final
decision is written only after both remote jobs pass no-inference acceptance.
