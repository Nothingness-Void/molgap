# K1 StatelessPairBridge 100K

This prospective V5 experiment tests one mechanism: repeated current-layer
ordered-pair flow with direct pair-to-node returns beside the unchanged K1-v4
exchanges, without persistent pair memory.

It is the matched alternative to `K1 RecurrentPairBridge`. Read `protocol.md`,
`training_contract.json`, and `trajectory.json` before compute release. The
immutable K1 reference is reused; it is not retrained.
