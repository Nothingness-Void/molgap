# V5 legacy evidence migration

This directory answers one question: which historical V4 screening evidence can
be represented under the V5 outcome model without rewriting history?

Migration is non-destructive. Original V4 contracts, acceptance files,
decisions, artifacts, and hashes remain authoritative for what was executed.
A V5 sidecar may only add the seven separated outcome fields, recovered cost
scope, role history, and explicit evidence gaps.

See `decision.md` for the local evidence audit and the migration boundary.
