# Geometry component attribution

This desktop-owned question tests what can be learned from the accepted
distance-plus-angle 500K pair before allocating another accelerator run.

- `protocol.md` freezes the existing-prediction diagnostic and its limits.
- `rml/` holds the prospective RML record created by the project planner.
- `analysis.json` and `decision.md` will hold the accepted result and decision.

The diagnostic uses the already consumed internal development role. It does
not access official validation or test roles, run model inference, or retrain a
reference.
