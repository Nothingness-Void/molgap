# GPTrans shortest-path profiling release decision

Decision date: 2026-09-18

The profiling-only contract in `profiling_contract.json` was frozen to measure
online shortest-path reconstruction against an exact cached integer tensor on
the accepted 500K train role. It authorized one short Kunshan DCU task and no
scientific training result, development evaluation, protected-role access,
architecture change, or training-contract change.

The terminal profiling result was intentionally left unresolved at release
time. `STATUS.md` owns the remote job identity; a later dated decision must cite
accepted machine evidence before an implementation follow-up can be released.
