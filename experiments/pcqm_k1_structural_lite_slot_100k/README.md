# K1 StructuralLite Slot 100K

This directory records a prospective K1 question that terminated as
`NO_TRAIN` after cross-branch evidence reconciliation. It does not authorize
implementation or training.

The candidate keeps the complete K1 local and persistent-edge backbone, adds
the already-supported zero-initialized selective MoSE residual beside RWSE16,
removes the mathematically degenerate self-attention operation from K1's
single molecular slot, and returns the slot uniformly to valid atoms.

Read `analysis.md`, then `protocol.md`, then `trajectory.json`. The protocol is
retained as the evaluated proposal, not as an active release.
