# K1 retained hop-fusion qualification

Question: does the previously observed fixed equal blend of the accepted
hop-shell arms improve on existing retained K1 references sufficiently to
justify an integration experiment?

This is saved-prediction CPU arithmetic. No training, checkpoint inference,
weight fitting, remote retrieval or protected-role access is performed.
The prior descriptive blend is already known; this question concerns its
incremental value over existing references, not rediscovery of that number.
