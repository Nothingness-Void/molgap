# Functional-group token terminal decision

The frozen seed-42 PCQM-100K candidate completed 40 epochs and passed
saved-artifact acceptance without model inference. Data, row order, optimizer,
schedule, selection, deterministic FP32/no-TF32 execution, physical batch 128,
and role access matched the immutable K1-v4 reference. Official validation,
test-dev, and challenge roles remained unread.

The candidate reached `0.1398314089 eV` development Gap MAE versus K1-v4 at
`0.1413736343 eV`, a gain of `0.0015422255 eV`. The paired candidate-minus-
reference error interval was `[-0.0024149091, -0.0006714036] eV`, so the
direction is favorable. The prospectively frozen material gate was `0.003 eV`
and was not met. The best checkpoint was epoch 39 of 40.

The result supports chemistry-defined sparse relation content, but not this
standalone group-token architecture as a promotion candidate. It is classified
`POSITIVE_BELOW_GATE`; no repeat seed, scale bridge, protected role, full run,
or desktop handoff is authorized. The exact standalone route is closed.

The retained mechanistic implication is narrower: chemistry roles contain
signal complementary to generic node-state communication. A later experiment
may use them to condition an already validated selective relation mechanism,
but may not simply add another parallel group-token branch.
