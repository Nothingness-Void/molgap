# Evidence selection

Two independent V4 screens produced aligned, favorable paired-error intervals:

- no slot attention: `0.0017627031 eV` gain;
- uniform normalized return: `0.0018262863 eV` gain.

Each effect is below the `0.003 eV` run-variation/materiality floor. Their
equations affect different portions of the same exchange: the first removes a
length-one latent processor; the second changes only recipient allocation.
Their optimistic additive estimate is a `0.0035889894 eV` gain, but interaction
may be sub-additive. This one run tests that interaction directly. It does not
authorize further K1 simplification tuning.

K1 geometry was not selected for the parallel route: the existing 500K
contextual evidence suggests only about `0.0005 eV` change for K1 and lacks a
V4 causal comparator. K1-G and K1-R are already closed.
