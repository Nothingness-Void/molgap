# K1 frozen equal-blend transfer

Read [terminal decision](terminal_decision.md) and [analysis](analysis_zh.md).
The prospective [protocol](protocol.md) binds clean retained-checkpoint
inference on a separate 50K internal-development cohort, without training.

`prepare.py` binds accepted inputs and invokes the shared RML planner;
`run.py` calls the K1 frozen inference helper and existing paired bootstrap;
`close.py` is the frozen draft translator; its migration-field mapping was
rejected before publication. `finalize_export.py` applies the accepted V5
metadata-only export semantics and calls the shared finalizer, preserving the
original draft and correction record without rerunning inference. Large source
checkpoints and graph shards remain hash-bound retained local inputs.
Aligned generated predictions are small independently retained artifacts.
Neither the original training verdicts nor operational model recommendation
are changed by this accepted diagnostic.
