# GPTrans pair-state normalization placement

This desktop-owned V5 screen tests two parameter-free normalization placements
around the persistent GPTrans pair-state residual. The T4x2 Kaggle package runs
one isolated candidate per device against the immutable accepted GPTrans-T
100K reference; it does not retrain that reference.

See `protocol.md` and `training_contract.json` for the frozen question.
