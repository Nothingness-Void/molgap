# Acquisition Evidence

This directory contains frozen sampling contracts and reports for the repaired
and replacement datasets used by the current experiment history. It is not a
live queue and it does not define the current model. Read `CURRENT_STATE.md`
for live truth and the relevant experiment `README.md`/`decision.md` for a
specific dataset.

The older Phase 3, Phase 6, and Phase 7 payloads referenced by some reports are
under `data/raw/archive/legacy/`. Their source paths inside dated JSON records
are historical provenance and should not be treated as executable defaults.
