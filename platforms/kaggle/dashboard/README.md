# Kaggle dashboard on Linux

Use a trusted host with the reviewed MolGap checkout at /opt/molgap, Python 3.10+ and a project venv at .venv. Use the existing MolGap environment including requests and the Kaggle SDK for kernel status. Verify collector imports from platforms/kaggle with the venv: `python -c "import check_logs, check_quota"`. The web reader uses the standard library. It listens on 127.0.0.1:8766. The collector reads GPU quota and optionally queries exact owner/kernel references. It never starts a kernel.

1. Create locked service users kaggle-dashboard and kaggle-dashboard-web and group kaggle-dashboard. Make /etc/kaggle-dashboard accessible only to the collector and root. Provision the authorized username/key JSON files there (mode 0600, collector owner). Copy options.example to /etc/kaggle-dashboard/options. Repeat --credentials for extra accounts, and --kernel owner/slug for each kernel to display. Keep account order stable; Account N is the Nth configured credential. If changing account order or identity, stop the timer and collector and move the old snapshot aside first.
2. Install the adjacent units in /etc/systemd/system. Run `systemd-analyze verify /etc/systemd/system/kaggle-dashboard*.service /etc/systemd/system/kaggle-dashboard.timer`, then `systemctl daemon-reload` and `systemctl enable --now kaggle-dashboard.timer kaggle-dashboard-web.service`. Check `curl -fsS http://127.0.0.1:8766/api/status`. Each cycle waits 120 seconds after the previous one. Quota failures retain the last measurement per account. An unknown kernel state or failed account marks the result partial; a stopped collector marks it stale after five minutes.
3. Use a separate Kaggle hostname and follow the [IMS Access setup, Agent credential and mobile acceptance checks](../../ims/dashboard/README.md). Install the Access policies **before** adding the hostname to the named tunnel. Put the Kaggle ingress before its final 404 rule, targeting http://127.0.0.1:8766. Leave the origin port closed to LAN/public traffic. Verify anonymous access fails, the named viewer can refresh and the restricted Agent token can fetch only /api/status.
4. To upgrade, stop the timer, collector and web service, save the old checkout revision, units and snapshot, install the reviewed new files, verify units, reload and start the timer and reader. Restore those saved versions to roll back. No collector credential is needed for the web service.
