# SCNet Evidence Records

This directory stores compact retrieved manifests from SCNet jobs. Large model,
prediction, cache, and log payloads remain local and are ignored by Git.

- `pcqm_gptrans_t_core_500k_0c0108e/completion_manifest.json` records the
  completed GPTrans-T 500K run identity and training trace; its prediction
  tensor is intentionally not tracked.
