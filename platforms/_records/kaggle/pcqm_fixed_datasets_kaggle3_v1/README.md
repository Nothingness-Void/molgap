official-train-derived PCQM4Mv2 graph datasets:

- `nvoid912/pcqm4mv2-ogb-fixed-100k-v1`
- `nvoid912/pcqm4mv2-ogb-fixed-500k-scnet-v1`

The payloads were downloaded from the accepted Kaggle2 mirrors without graph
recomputation. The remote manifests retain the Kaggle1/Kaggle2 SHA256
identities, and the Kaggle3 file inventories match every declared graph shard
path and size. Both datasets are private and licensed CC BY 4.0.

Neither mirror contains official validation, test-dev, test-challenge, 1M, or
full-train payloads. The per-role `acceptance.json` files are the compact
mechanical authorities. These mirrors install data infrastructure only; they
do not replace or retroactively modify any frozen scientific training contract.
