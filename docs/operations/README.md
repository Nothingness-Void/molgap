# Working guides

Use three entry points; follow detailed contracts only for the operation at hand.

| Task | Guide |
|---|---|
| Modify, prepare or accept an experiment | [Experiment workflow](EXPERIMENT_WORKFLOW.md) |
| Interpret results, compare or decide | [Research protocol](RESEARCH_PROTOCOL.md) |
| Repair the environment, run checks or retire local storage | [Repository maintenance](REPOSITORY_MAINTENANCE.md) |

Platform access boundaries remain with their workload skills and
[platform routing](../../platforms/README.md). Historical acceptance and frozen
contracts remain evidence; they are not extra steps to repeat for every change.
