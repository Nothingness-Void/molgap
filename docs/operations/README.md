# MolGap V5 operations

These are the durable copies of the user-authorized MolGap V5 contracts.

- `MOLGAP_COMMON_DIRECTION_V5_FINAL.md` defines the shared machine topology,
  evidence boundaries, state separation, screening funnel, and V5 change policy.
- `SERVER_AGENT_HANDOFF_V5_FINAL.md` defines the server-only A/B loop, its
  30-minute mechanical monitor, local durability, acceptance, and desktop boundary.

The V5 files supersede older V3/V4 handoff documents. `AGENTS.md` remains a
short navigation file; it does not duplicate the full contracts.
